# Dual-Controlled-Robot-Car
This prototype robot car operates in two control modes: autonomous and remote-controlled. 
Using a custom mobile app connected via Bluetooth, you can switch seamlessly between modes. 
In remote-controlled mode, the car’s movement and navigation are fully directed from the app, while its onboard sensors still ensure it automatically stops when an obstacle is detected. 
In autonomous mode, the robot navigates entirely on its own without human input.
